# TaskHive - Платформа для поиска подработок

TaskHive — это инновационная платформа для поиска подработок и краткосрочных вакансий, разработанная специально для рынка России и стран СНГ.

## 🎯 Основные возможности

### Для работников
- **Поиск вакансий** - Просмотр 50,000+ активных вакансий по категориям (курьер, склад, доставка, ритейл и др.)
- **Быстрые отклики** - Откликнитесь на вакансию в один клик
- **Личный кабинет** - Управляйте откликами, просматривайте историю и рейтинг
- **Система рейтинга** - Получайте отзывы от работодателей и повышайте свой рейтинг
- **Скоринговая система** - Система оценки на основе IQ и профессиональных навыков
- **Чаты** - Общайтесь с работодателями в реальном времени
- **Уведомления** - Получайте уведомления о новых вакансиях и откликах

### Для работодателей
- **Размещение вакансий** - Создавайте вакансии с подробным описанием
- **Управление откликами** - Просматривайте отклики и выбирайте лучших кандидатов
- **Система рейтинга** - Оценивайте работников и оставляйте отзывы
- **Горячие вакансии** - Выделите вакансию как горячую для большей видимости
- **Партнерские программы** - Статус Платинум, Голд или Сильвер партнера

## 🛠️ Технический стек

### Backend
- **Express.js** - Web фреймворк
- **tRPC** - Type-safe RPC framework
- **Drizzle ORM** - ORM для работы с БД
- **MySQL/TiDB** - База данных
- **Node.js** - Runtime

### Frontend
- **React 19** - UI библиотека
- **Tailwind CSS 4** - Утилит-первый CSS фреймворк
- **shadcn/ui** - Компоненты UI
- **Wouter** - Маршрутизация
- **TypeScript** - Type-safe JavaScript

## 🚀 Быстрый старт

### Установка зависимостей
```bash
pnpm install
```

### Запуск в режиме разработки
```bash
pnpm dev
```

Приложение будет доступно по адресу `http://localhost:3000`

### Миграция БД
```bash
pnpm db:push
```

### Запуск тестов
```bash
pnpm test
```

### Сборка для продакшена
```bash
pnpm build
pnpm start
```

## 📊 Основные таблицы БД

### users
Основная таблица пользователей с информацией об аутентификации.

### userProfiles
Расширенные профили с информацией о типе пользователя (работник/работодатель), навыках, опыте, рейтинге.

### jobs
Вакансии с информацией о зарплате, требованиях, категории, регионе, статусе.

### applications
Отклики на вакансии с информацией о статусе, рейтинге, отзывах.

### scoringRecords
Скоринговые оценки пользователей (IQ, профессиональные навыки, надежность).

### chats
Чаты между пользователями с информацией об участниках и последнем сообщении.

### messages
Сообщения в чатах с информацией об отправителе, содержании, статусе прочтения.

### notifications
Уведомления для пользователей о новых вакансиях, откликах, сообщениях.

### partners
Партнеры и спонсоры платформы с информацией о статусе (Платинум, Голд, Сильвер).

## 📝 API Документация

### Jobs Router
- `jobs.list` - Получить список вакансий с пагинацией
- `jobs.getById` - Получить вакансию по ID
- `jobs.byCategory` - Получить вакансии по категории
- `jobs.hotJobs` - Получить горячие вакансии
- `jobs.create` - Создать новую вакансию (требует авторизации)

### Applications Router
- `applications.submit` - Подать отклик на вакансию
- `applications.getByWorker` - Получить отклики работника
- `applications.getByJob` - Получить отклики на вакансию

### Profile Router
- `profile.get` - Получить профиль пользователя
- `profile.create` - Создать профиль

### Scoring Router
- `scoring.get` - Получить скоринг пользователя
- `scoring.calculate` - Рассчитать скоринг на основе IQ и профессиональных навыков

### Chats Router
- `chats.list` - Получить список чатов пользователя
- `chats.create` - Создать новый чат
- `chats.sendMessage` - Отправить сообщение
- `chats.getMessages` - Получить сообщения чата

### Notifications Router
- `notifications.list` - Получить уведомления пользователя
- `notifications.create` - Создать уведомление

### Partners Router
- `partners.list` - Получить список активных партнеров
