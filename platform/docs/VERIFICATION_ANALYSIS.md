# Анализ необходимости верификации документов

**Дата:** 25 января 2026 г.  
**Версия:** 1.0

---

## 📋 Резюме

**Вывод:** Верификация документов **НЕ критична** для MVP, но **рекомендуется** для полноценной платформы.

| Аспект | Статус |
|--------|--------|
| **Требование по закону РФ** | ⚠️ Зависит от типа операций |
| **Для MVP** | ❌ Не обязательна |
| **Для платежей** | ⚠️ Зависит от платежной системы |
| **Для вывода денег** | ✅ Может быть требуемо |
| **Приоритет** | 🟡 MEDIUM (после платежей) |

---

## 🔍 Анализ по типам операций

### 1. Платформа как маркетплейс (TaskHive)

**Статус:** Верификация **НЕ требуется** по закону РФ

**Почему:**
- TaskHive - это платформа, а не работодатель
- Исполнители - независимые подрядчики
- Платформа не несёт ответственность за их деятельность
- Нет прямого трудового отношения

**Требования:**
- ✅ Пользовательское соглашение
- ✅ Политика конфиденциальности
- ✅ Система рейтинга и отзывов
- ✅ Механизм разрешения споров
- ❌ Верификация документов (не требуется)

---

### 2. Платежи и вывод денег

**Статус:** Верификация **может быть требуемо** платежной системой

**Платежная система** | **Требует верификацию** | **Примечание**
---|---|---
Yandex.Kassa | ⚠️ Для крупных сумм | Выше 600k рублей/месяц
Sber Pay | ⚠️ Для крупных сумм | Выше 500k рублей/месяц
Tinkoff | ⚠️ Для крупных сумм | Выше 1M рублей/месяц
Stripe | ✅ Да, требуется | Для всех пользователей

**Вывод:** Верификация требуется **платежной системой**, а не законом РФ.

---

### 3. Налоговые требования

**Статус:** Верификация **НЕ требуется** для платформы, но требуется для пользователей

**Для исполнителей:**
- Если заработок > 4M рублей/год → нужна регистрация как ИП
- Если заработок < 4M рублей/год → может быть физическое лицо
- Налоги платит сам исполнитель

**Для платформы:**
- Нужно вести реестр исполнителей (для налоговой)
- Нужно отправлять отчёты в налоговую
- ❌ Не нужно проверять документы пользователей

---

## ✅ Рекомендации

### Для MVP (первые 3 месяца)

**НЕ добавлять верификацию документов**

**Вместо этого:**
1. ✅ Добавить систему рейтинга и отзывов
2. ✅ Добавить механизм разрешения споров
3. ✅ Добавить AI-модерацию контента
4. ✅ Добавить систему платежей
5. ✅ Добавить пользовательское соглашение

**Результат:** Полнофункциональная платформа, готовая к запуску

---

### Для Phase 2 (месяцы 4-6)

**Добавить верификацию (опционально)**

**Если решите добавить:**
1. Простая верификация (селфи + паспорт)
2. Автоматическая проверка через API
3. Ручная проверка для крупных сумм
4. Система повторной верификации

**Сервисы:**
- Яндекс.Паспорт (для РФ)
- Veriff (международный)
- IDology (для США)

---

### Для Phase 3 (месяцы 7-12)

**Полная верификация**

**Если платформа масштабируется:**
1. Биометрическая верификация
2. Проверка кредитной истории
3. Проверка судимостей
4. Проверка санкционных списков

TaskHive ближе к Upwork/Fiverr → верификация **опциональна**.

## 🎯 Финальная рекомендация

### Для MVP: ❌ НЕ добавлять верификацию

**Причины:**
1. Не требуется по закону РФ
2. Усложняет onboarding
3. Снижает скорость регистрации
4. Платежные системы сами проверят при необходимости

**Вместо этого:**
- Добавить систему рейтинга
- Добавить механизм разрешения споров
- Добавить AI-модерацию
- Добавить систему платежей

---

### Для Phase 2: ⚠️ Рассмотреть верификацию

**Если:**
- Платформа растёт быстро (100k+ пользователей)
- Есть проблемы с мошенничеством
- Платежные системы требуют верификацию
- Пользователи просят верификацию

**Тогда:**
- Добавить опциональную верификацию
- Использовать Яндекс.Паспорт для РФ
- Давать бейджи верифицированным пользователям

---

### Для Phase 3: ✅ Полная верификация

**Если:**
- Платформа масштабируется (1M+ пользователей)
- Нужна максимальная безопасность
- Есть бюджет на интеграцию

**Тогда:**
- Добавить обязательную верификацию
- Использовать биометрию
- Проверять санкционные списки
