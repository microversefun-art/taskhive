## 🚀 Развёртывание

### Docker
```bash
docker-compose up -d
```

### Environment Variables
```bash
cp .env.example .env
# Заполнить необходимые переменные
```

### Миграции БД
```bash
pnpm db:push
```

### Запуск
```bash
pnpm dev
```

## 📱 Мобильные приложения

### Google Play
```bash
npm run build:android
npm run submit:android
```

### RuStore
```bash
npm run build:android
# Загрузить вручную в RuStore Console
```

### App Store
```bash
npm run build:ios
npm run submit:ios
```
