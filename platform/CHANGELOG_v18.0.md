# TaskHive v18.0 - Changelog

## 🎉 Что нового

### 4 ключевые фичи БЕЗ персональных данных

#### 1. 🏦 Эскроу-система (Escrow Management)
- **Файл:** `server/escrow/escrow-manager.ts`
- **Функции:**
  - Удержание денег до завершения проекта
  - Автоматический выпуск денег исполнителю
  - Возврат денег клиенту при отмене
  - Система спора (Dispute Resolution)
  - Арбитраж (Client Win / Executor Win / Split)
- **Статусы:** pending → held → released/refunded/disputed
- **Финансовый прогноз:** +1M₽/месяц комиссия
- **Соответствие:** ФЗ-115 (противодействие ОД/ФТ)

#### 2. 🛡️ Система страхования (Insurance Plans)
- **Файл:** `server/insurance/insurance-manager.ts`
- **Планы:**
  - Executor Protection (защита исполнителя от невыплаты)
  - Client Protection (защита клиента от некачественной работы)
  - Both (комбинированный план)
- **Функции:**
  - Управление планами страховки
  - Подача страховых претензий
  - Одобрение/отклонение претензий
  - Выплата по претензиям
  - Отслеживание статистики
- **Цена:** 99₽-999₽/месяц
- **Финансовый прогноз:** +500k₽/месяц
- **Соответствие:** ФЗ-40 (страховое дело)

#### 3. 📹 Видеоинтервью (Video Interviews)
- **Файл:** `server/video/video-interview-manager.ts`
- **Функции:**
  - Планирование видеоинтервью между клиентом и исполнителем
  - Запись видео (хранится в РФ на S3)
  - Согласие на запись обеих сторон
  - История интервью
  - Заметки после интервью
  - Статистика по длительности
- **Статусы:** scheduled → in_progress → completed/cancelled
- **Финансовый прогноз:** +15% конверсии
- **Соответствие:** ФЗ-152 (согласие на запись), ФСТЭК (локализация)

#### 4. 🌐 Интеграция с маркетплейсами (Marketplace Sync)
- **Файл:** `server/integrations/marketplace-sync.ts`
- **Поддерживаемые маркетплейсы:**
  - Яндекс.Работа (Yandex.Rabota)
  - HeadHunter (HH.ru)
  - Авито (Avito)
- **Функции:**
  - Подключение маркетплейса (OAuth)
  - Публикация вакансий на маркетплейсы
  - Синхронизация статистики (просмотры, заявки)
  - Архивирование листингов
  - Получение статистики по маркетплейсам
- **Финансовый прогноз:** +10-15% новых пользователей
- **Соответствие:** API маркетплейсов, ФЗ-152

## 📋 API Endpoints (готовы к реализации)

### Эскроу
```
POST /api/trpc/escrow.create                 — Создать эскроу
POST /api/trpc/escrow.hold                   — Удержать деньги
POST /api/trpc/escrow.release                — Выпустить деньги
POST /api/trpc/escrow.refund                 — Вернуть деньги
POST /api/trpc/escrow.openDispute            — Открыть спор
POST /api/trpc/escrow.resolveDispute         — Решить спор
GET /api/trpc/escrow.getUserEscrows          — Получить эскроу пользователя
GET /api/trpc/escrow.getStats                — Получить статистику
```

### Страховка
```
POST /api/trpc/insurance.createPlan          — Создать план
POST /api/trpc/insurance.createClaim         — Подать претензию
POST /api/trpc/insurance.approveClaim        — Одобрить претензию
POST /api/trpc/insurance.rejectClaim         — Отклонить претензию
POST /api/trpc/insurance.payClaim            — Выплатить по претензии
GET /api/trpc/insurance.getUserPlans         — Получить планы пользователя
GET /api/trpc/insurance.getStats             — Получить статистику
```

### Видеоинтервью
```
POST /api/trpc/video.schedule                — Запланировать интервью
POST /api/trpc/video.start                   — Начать интервью
POST /api/trpc/video.complete                — Завершить интервью
POST /api/trpc/video.setConsent              — Установить согласие
GET /api/trpc/video.getUserInterviews        — Получить интервью пользователя
GET /api/trpc/video.getStats                 — Получить статистику
```

### Маркетплейсы
```
POST /api/trpc/marketplace.connect           — Подключить маркетплейс
POST /api/trpc/marketplace.publish           — Опубликовать вакансию
POST /api/trpc/marketplace.sync              — Синхронизировать листинги
GET /api/trpc/marketplace.getStats           — Получить статистику
```
