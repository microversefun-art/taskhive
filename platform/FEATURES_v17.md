# TaskHive v17.0 - 4 Новые Фичи

## 1. 🏆 Лидерборд рефереров (Referral Leaderboard)

### Описание
Система рейтинга рефереров с отслеживанием заработков и активных приглашённых пользователей.

### Функциональность
- **Топ-100 рефереров** по общему заработку
- **Топ-100 рефереров** по количеству активных рефералов
- **Еженедельный лидерборд** (обновляется каждый понедельник)
- **Ежемесячный лидерборд** (обновляется 1-го числа)
- **Персональная позиция** в каждом лидербордеме
- **Бейджи и тренды** (👑, 🥈, 🥉, 🔥, ⚡)

### Файлы
- `server/referrals/referral-leaderboard.ts` — бэкенд логика
- `client/src/pages/ReferrerLeaderboard.tsx` — UI страница (нужно создать)
- `client/src/components/LeaderboardTable.tsx` — компонент таблицы (нужно создать)

### API endpoints (нужно добавить в routers.ts)
```typescript
trpc.referrals.leaderboard.earnings.query()
trpc.referrals.leaderboard.activity.query()
trpc.referrals.leaderboard.myPosition.query()
```

### Финансовый прогноз
- **+15% активных рефереров** благодаря геймификации
- **+25% среднего заработка** на реферера (мотивация через лидерборд)

## 2. ⭐ Система рейтинга исполнителей (Rating System)

### Описание

### Функциональность

- **Количество отзывов** (для доверия)
- **Фильтр по рейтингу** при поиске исполнителей
- **Бейджи качества** (⭐⭐⭐⭐⭐ 4.8+, ⭐⭐⭐⭐ 4.0+)

## 4. 💎 Премиум-листинги (Premium Listings)

### Описание
Платная услуга для выделения вакансий в поиске и рекомендациях.

### Функциональность
- **3 уровня премиума:**
  - **Базовый** (99₽/месяц) — выделение в поиске
  - **Стандартный** (299₽/месяц) — выделение + рекомендации
  - **Премиум** (999₽/месяц) — выделение + рекомендации + топ-позиция

- **Автоматическое продление** (ежемесячная подписка)
- **Отмена в любой момент**
- **Статистика просмотров** (сколько раз видели вакансию)
- **A/B тестирование** заголовков

### Файлы
- `server/premium/premium-listings.ts` — бэкенд логика (нужно создать)
- `client/src/pages/PremiumListings.tsx` — страница управления (нужно создать)
- `client/src/components/PremiumUpgradeModal.tsx` — модал покупки (нужно создать)

### API endpoints (нужно добавить)
```typescript
trpc.premium.subscribe.mutation()
trpc.premium.cancel.mutation()
trpc.premium.getStats.query()
```

### Финансовый прогноз
- **10% вакансий** будут премиум (консервативно)
- **Средний доход:** 99₽ × 10% × 100,000 вакансий = **99M₽/месяц** 🚀
- **Реалистичный прогноз:** 2-3% премиум = **2-3M₽/месяц**
