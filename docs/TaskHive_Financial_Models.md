## 2. ОСНОВНЫЕ ФИНАНСОВЫЕ МЕТРИКИ

### 2.1 Метрики Доходов

**Monthly Recurring Revenue (MRR)**
```
MRR = Количество активных клиентов × Средний размер сделки
```

**Annual Recurring Revenue (ARR)**
```
ARR = MRR × 12
```

**Customer Acquisition Cost (CAC)**
```
CAC = (Зарплата продаж + Маркетинг) / Количество новых клиентов
```

**Customer Lifetime Value (LTV)**
```
LTV = Average contract value × (1 / Churn rate)
```

**LTV/CAC Ratio**
```
LTV/CAC = LTV / CAC
```

**Payback Period**
```
Payback Period = CAC / (MRR - COGS)
```

### 2.2 Метрики Прибыльности

**Gross Profit**
```
Gross Profit = Revenue - Cost of Goods Sold (COGS)
```

**Gross Profit Margin**
```
Gross Profit Margin = Gross Profit / Revenue × 100%
```

**Operating Profit (EBITDA)**
```
EBITDA = Gross Profit - Operating Expenses
```

**Operating Margin**
```
Operating Margin = EBITDA / Revenue × 100%
```

**Net Profit**
```
Net Profit = EBITDA - Taxes - Interest
```

## 5. РАСЧЁТ LTV/CAC

### 5.1 Расчёт CAC (Customer Acquisition Cost)

**2026 CAC расчёт:**

```
Затраты на продажи и маркетинг = 7.56M (персонал) + 1.2M (маркетинг) = 8.76M
Новых клиентов = 60
CAC = 8.76M / 60 = 146,000₽
```

**Оптимизированный CAC (с масштабированием):**
```
CAC = 5,000₽ (при оптимизации процесса и масштабировании)
```

### 5.2 Расчёт LTV (Customer Lifetime Value)

**2026 LTV расчёт:**

```
Average Contract Value = 15,000₽/месяц × 12 = 180,000₽/год
Monthly Churn Rate = 5% (типичный для SaaS)
Average Customer Lifetime = 1 / 0.05 = 20 месяцев
LTV = 15,000₽ × 20 = 300,000₽
```

**Консервативный LTV:**
```
LTV = 180,000₽ (1 год минимум)
```

### 5.3 LTV/CAC Ratio

**Оптимизированный сценарий:**
```
LTV/CAC = 180,000₽ / 5,000₽ = 36:1
```

**Консервативный сценарий:**
```
LTV/CAC = 180,000₽ / 146,000₽ = 1.23:1 (ПЛОХО - нужна оптимизация)
```

**Интерпретация:**
- LTV/CAC > 3:1 = Здоровый бизнес
- LTV/CAC > 5:1 = Отличный бизнес
- LTV/CAC > 10:1 = Исключительный бизнес
- LTV/CAC < 1:1 = Неустойчивый бизнес

**Вывод:** Нужна оптимизация CAC через масштабирование и автоматизацию.

## 6. ROI КАЛЬКУЛЯТОР ДЛЯ КЛИЕНТОВ

### 6.1 Как Считать ROI для Клиента

**Формула ROI:**
```
ROI = (Экономия - Инвестиция) / Инвестиция × 100%
```

**Компоненты Экономии:**

1. **Сокращение времени найма**
   - Текущее время найма: 45 дней
   - Время найма с TaskHive: 15 дней
   - Экономия: 30 дней × 1 день = 30 дней
   - Стоимость дня: 10,000₽ (зарплата HR + потери производительности)
   - Экономия: 30 × 10,000₽ = 300,000₽

2. **Снижение затрат на рекрутинг**
   - Текущие затраты: 50,000₽ на одного нанятого
   - Затраты с TaskHive: 35,000₽ на одного нанятого
   - Экономия на одного: 15,000₽
   - Количество найма в год: 20 человек
   - Экономия: 20 × 15,000₽ = 300,000₽

3. **Улучшение качества найма**
   - Текущий turnover: 30% в год
   - Turnover с TaskHive: 20% в год
   - Экономия на переобучение: 50,000₽ × 10 человек = 500,000₽

**Итого Экономия в год: 1,100,000₽**

### 6.2 Пример ROI Расчёта для SMB Компании

**Входные данные:**
- Размер компании: 100 сотрудников
- Текущие затраты на найм: 50,000₽ на одного
- Количество найма в год: 20 человек
- Средняя зарплата: 60,000₽/месяц
- Стоимость дня работы HR: 10,000₽

**Расчёт Экономии:**

| Компонент | Расчёт | Сумма |
|-----------|--------|-------|
| Сокращение времени найма | 30 дней × 10,000₽ | 300,000₽ |
| Снижение затрат на рекрутинг | 20 × 15,000₽ | 300,000₽ |
| Улучшение качества найма | 10 × 50,000₽ | 500,000₽ |
| **ИТОГО ЭКОНОМИЯ** | | **1,100,000₽** |

**Расчёт Инвестиции:**

| Компонент | Расчёт | Сумма |
|-----------|--------|-------|
| Подписка TaskHive | 15,000₽ × 12 | 180,000₽ |
| Обучение команды | 1 день × 5,000₽ | 5,000₽ |
| Интеграция с системами | 1 день × 10,000₽ | 10,000₽ |
| **ИТОГО ИНВЕСТИЦИЯ** | | **195,000₽** |

**Расчёт ROI:**

```
ROI = (1,100,000₽ - 195,000₽) / 195,000₽ × 100%
ROI = 905,000₽ / 195,000₽ × 100%
ROI = 464%
```

**Payback Period:**
```
Payback Period = 195,000₽ / (1,100,000₽ / 12)
Payback Period = 195,000₽ / 91,667₽
Payback Period = 2.1 месяца
```

**Вывод:** Инвестиция окупится за 2 месяца, ROI составит 464% за год.

## 8. BREAK-EVEN АНАЛИЗ

### 8.1 Точка Безубыточности

**Формула Break-even:**
```
Break-even = Fixed Costs / (Price - Variable Cost per Unit)
```

**2026 Расчёт:**

```
Fixed Costs = 10.8M (все затраты)
Price per Customer = 15,000₽/месяц = 180,000₽/год
Variable Cost per Customer = COGS = 21% × 180,000₽ = 37,800₽
Contribution Margin = 180,000₽ - 37,800₽ = 142,200₽

Break-even = 10.8M / 142,200₽ = 75.9 клиентов
```

**Вывод:** Нужно 76 клиентов для достижения break-even в 2026.

### 8.2 Прогноз Break-even по Годам

**Вывод:**
