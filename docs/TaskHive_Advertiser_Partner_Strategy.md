## 📊 ИСПОЛНИТЕЛЬНОЕ РЕЗЮМЕ

TaskHive - платформа для поиска подработок с 400K+ пользователей в 2026 году. Предлагаем рекламодателям и партнёрам доступ к целевой аудитории работников и работодателей с высокой конверсией.

**Ключевые метрики:**
- **DAU:** 30K (Q1) → 400K (Q4 2026)
- **MAU:** 100K (Q1) → 1.2M (Q4 2026)
- **Средний возраст:** 18-45 лет
- **Основной доход:** 1,000-50,000₽/месяц
- **Активность:** 2-3 часа/день в приложении

## 💼 ПАРТНЕРСКИЕ ПРОГРАММЫ

### Программа 1: Партнеры-Рефереры (Низкий Барьер Входа)

**Описание:** Партнеры получают комиссию за каждого привлеченного клиента

**Условия:**
- Комиссия: 10-20% от первого платежа клиента
- Минимум: нет
- Максимум: нет
- Срок: 12 месяцев

**Примеры партнеров:**
- Блогеры и инфлюенсеры
- Консультанты по HR
- Бизнес-коучи
- Агентства по маркетингу

**Как работает:**
1. Партнер получает уникальную ссылку
2. Отправляет ссылку своей аудитории
3. Клиент переходит по ссылке и подписывается
4. Партнер получает комиссию

**Материалы для партнеров:**
- Презентация (PDF)
- Видео-обзор (2 мин)
- Баннеры (300x250, 728x90)
- Email шаблоны
- Текстовые описания

- Добавить call-to-action

4. **Value:** Ценность для компании (3-5 пунктов)
5. **Social Proof:** Примеры успеха (1-2 case studies)
